# 🐍 Snake Game

A classic Snake game built with vanilla JavaScript and HTML5 Canvas.

## Features

✨ **Game Features:**
- Classic snake gameplay
- Progressive difficulty (speed increases with score)
- Score tracking with persistent high score (using localStorage)
- Smooth animations and responsive design
- Beautiful gradient UI with modern styling

🎮 **How to Play:**
1. Open `index.html` in your web browser
2. Use **arrow keys** to move the snake
3. Eat the red food to grow and gain points
4. Avoid hitting the walls or yourself
5. Try to beat your high score!

## Controls

| Key | Action |
|-----|--------|
| ↑ Arrow Up | Move Up |
| ↓ Arrow Down | Move Down |
| ← Arrow Left | Move Left |
| → Arrow Right | Move Right |

## Scoring

- Each food eaten: **+10 points**
- Game speed increases every 100 points
- High score is automatically saved to your browser

## Files

- `index.html` - Main game page
- `styles.css` - Game styling and layout
- `game.js` - Game logic and mechanics

## No Dependencies

This game requires no external libraries or frameworks. It uses:
- Pure JavaScript (ES6+)
- HTML5 Canvas API
- CSS3 Flexbox & Gradients
- Browser localStorage API

## Browser Compatibility

Works on all modern browsers (Chrome, Firefox, Safari, Edge)
